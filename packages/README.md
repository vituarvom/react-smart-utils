# ⚡ React Smart Utils

A modern and modular collection of **React hooks, utilities, and components** — designed to make building React apps faster, cleaner, and smarter.  
Powered by the ecosystem of **[`@rsujs/core`](https://www.npmjs.com/package/@rsujs/core)**.

---

## 🚀 Features

- 🧠 Smart, reusable React hooks for everyday use  
- ⚙️ Modular architecture powered by `@rsujs/core`  
- 🎨 UI-ready extensions *(coming soon via `@rsujs/ui`)*  
- 🤖 AI-driven helpers *(coming soon via `@rsujs/ai`)*  
- ⚡ Built with TypeScript, fully typed, and tree-shakable  
- 🔄 ESM + CJS compatible builds  
- 💎 Open-source and developer-friendly  

---

## 📦 Installation

You can install either the main **React Smart Utils** library or specific modular subpackages.

### Option 1: Install the main package
```bash
npm install react-smart-utils
# or
yarn add react-smart-utils
```

### Option 2: Install the core package directly
```bash
npm install @rsujs/core
```

All submodules are designed to be lightweight and independent.
You can use them standalone or together via react-smart-utils.



# Development Setup

# Clone the repo
git clone https://github.com/vituarvom/react-smart-utils

# Move into the project
cd react-smart-utils

# Install dependencies
npm install

# Build all packages
npm run build
